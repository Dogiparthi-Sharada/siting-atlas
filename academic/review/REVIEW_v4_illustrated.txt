1.3.1  INNOVATION 1 -- the failure the four gates do not catch
--------------------------------------------------------------

Prior art on gated LLM writes DOES exist (survey arXiv:2608.14590; SafeNlidb
arXiv:2511.06778; text-to-SQL vulnerabilities arXiv:2211.15363; IEEE S&P 2026
"Words Become SQL"; plus shipping open-source: sqlgate, llm-safe-sql).

So "LLM proposes a write -> gates validate -> human approves" is well-trodden.

BUT. Every one of those protects DATA INTEGRITY. Your write target is not a
data table -- it is a PARAMETER OF A CAUSAL ESTIMATOR. That creates a failure
class nobody has studied. Worked example:


   PRESS RELEASE
   "Walmart opens a new sortation centre in Plano, TX"
        |
        v
   +-------------------------------------------------------------+
   | LLM extracts:  (33.0198, -96.6989, SORTATION)                |
   +-------------------------------------------------------------+
        |
        v
   +-------------------------------------------------------------+
   |  GATE 1   schema conformance .......................  PASS   |
   |  GATE 2   geocoding reachability (Plano is real) ...  PASS   |
   |  GATE 3   confidence threshold (0.94) ..............  PASS   |
   |  GATE 4   audit-log immutability ...................  PASS   |
   +-------------------------------------------------------------+
        |
        |  write lands in dim_logistics_nodes.  System reports SUCCESS.
        v
   +-------------------------------------------------------------+
   |                  BUT DOWNSTREAM  ...                        |
   +-------------------------------------------------------------+
        |
        v
     W matrix changes            (which ZCTAs are "neighbours")
        |
        v
     Donor pool changes          (Dallas ZCTAs move in/out of controls)
        |
        v
     theta changes               (the cannibalisation coefficient)
        |
        v
     NPV moves by MILLIONS
        |
        v
   +-------------------------------------------------------------+
   |   <<<  NOTHING IN GATES 1-4 CHECKS ANY OF THIS  >>>          |
   |   The write is "safe". The inference is broken.              |
   +-------------------------------------------------------------+


   THE FIX -- add two IDENTIFICATION gates.  This is the real contribution.

   +-------------------------------------------------------------------+
   | GATE 5  DONOR-POOL INTEGRITY                                      |
   |   Does this mutation move a unit currently serving as a control   |
   |   into a treated / spillover-contaminated state?                  |
   |   -> if yes, recompute the donor pool and FLAG the affected       |
   |      ZCTAs. Do not silently re-weight.                            |
   +-------------------------------------------------------------------+
   | GATE 6  ESTIMATE STABILITY                                        |
   |   Re-run theta with and without the mutation.                     |
   |   If |delta theta| > PRE-REGISTERED threshold                     |
   |   -> escalate to a human REGARDLESS of the HITL_REQUIRED flag,    |
   |      and surface the delta in the diff card.                      |
   +-------------------------------------------------------------------+

   Effort: ~2 days. You already estimate theta -- you just run it twice
   and diff.

   RESTATED CLAIM (defensible, narrow, publishable):
     "Existing work on gated LLM writes protects DATA integrity. We identify
      a distinct failure class -- INFERENTIAL integrity -- in which a write
      that satisfies every data-integrity gate nonetheless invalidates a
      downstream causal identification assumption, and we propose two
      identification gates that detect it."


1.3.2  INNOVATION 2 -- what actually survives
---------------------------------------------

v3 says W has been "fixed ex ante for four decades". Counter-examples, all

    Souza (2019)              estimation/selection of W in a spatial lag model

    Ahrens & Bhattacharjee       two-step Lasso estimation of W
    LeSage & Pace (2014)         "The Biggest Myth in Spatial Econometrics"

The save is that all of them update W through a DIFFERENT CHANNEL than you do:


   PRIOR ART  --  W as an ESTIMATED PARAMETER
   ------------------------------------------------------------------
        +----------------+
        | outcome panel  |----+
        |   Y(i,t)       |    |
        +----------------+    |
                |             | SAME data used for both
                |             |
                v             v
        +----------------+  +----------------+
        | estimate  W    |->| infer  theta   |
        +----------------+  +----------------+
             in-sample, statistical, ONCE


   THIS PROJECT  --  W as EVENT-DRIVEN STATE
   ------------------------------------------------------------------
        +----------------+          +---------------------------+
        | outcome panel  |          |  EXOGENOUS TEXT STREAM    |
        |   Y(i,t)       |          |  competitor announcements |
        +----------------+          +---------------------------+
                |                              |
                |                              v
                |                   +---------------------------+
                |                   | LLM extract + GATES 1-6   |
                |                   +---------------------------+
                |                              |
                |                              v
                |                   +---------------------------+
                |                   |   revise W  (between      |
                |                   |   estimation cycles)      |
                |                   +---------------------------+
                |                              |
                +--------------+---------------+
                               v
                     +--------------------+
                     |  re-infer  theta   |
                     +--------------------+
                        streaming, out-of-band, REPEATEDLY


   AND THEN -- TURN LeSAGE & PACE INTO YOUR EXPERIMENT.

   natural test of that claim. So PRE-REGISTER it:

      RQ2 (rewritten):  Does event-driven revision of W materially change

                    theta MOVES  /             \  theta DOESN'T MOVE
                                v               v
              +--------------------------+  +--------------------------+
              | You push back on a known |  | You CONFIRM a known      |
              | claim in spatial econ,   |  | claim under a NOVEL      |
              | using a new update       |  | perturbation, AND report |
              | channel.                 |  | an honest engineering    |

   (a) CONFORMAL PREDICTION -- highest return on effort in this whole review
   -------------------------------------------------------------------------
       Split conformal gives DISTRIBUTION-FREE, FINITE-SAMPLE coverage.
       ~30 lines of code. Angelopoulos & Bates (2021), arXiv:2107.07511.

       It lets you say:

            "Our 90% prediction intervals empirically covered 90.2% of
             held-out ZCTAs."

       That is a VERIFIED claim, not a modelling assumption. Most credible
       sentence you can put in a methods paper for the least work.
       IF YOU IMPLEMENT ONE THING FROM THIS REVIEW, IMPLEMENT THIS.


   (c) TOP-K RANK STABILITY -- the number an executive actually needs
   ------------------------------------------------------------------
       The real question is not "what's your MAPE". It is:

            "If your inputs are wrong within their uncertainty bands,
             does your RECOMMENDATION change?"

       Across the 10,000 Monte Carlo draws you already run, report:

          ZCTA      appears in TOP 10 in ...
          -------------------------------------------------------------
          94608     ############################################ 87%  STABLE
          94501     ##################################           68%  stable
          94612     #################                          34%  UNSTABLE
          94577     ########                                   16%  UNSTABLE

          "ZCTA 94612 appears in the top ten in only 34% of draws. Its

       Falls straight out of simulation you are already running. Almost no
       student project reports it. Turns uncertainty from an apology into a
       product feature.

THE DISTINCTION THAT SAVES THE SURVIVORS: CAUSAL vs GEOMETRIC
--------------------------------------------------------------

   Esri's "Measure Cannibalization" is a TRADE-AREA OVERLAP calculation.
   It is DESCRIPTIVE GEOMETRY. It answers "how much do these two trade
   areas overlap?"

   opened?" -- there is no counterfactual, no donor pool, no treatment
   effect.

Q1: "AMAZON ALREADY DOES THIS. WHAT'S NEW?"
-------------------------------------------
  "The definitive academic treatment is Houde, Newberry and Seim in
   Econometrica 2023 -- the two-day fulfilment network, state grain, through
   2018, on data nobody else can obtain. We do the sub-24-hour network at
   ZCTA grain through 2026 on entirely public data, and we ship a running
   tool.

   Beyond the reproduction, we contribute two things the literature doesn't
   have. First, a failure class in LLM-agent systems where a write passes
   every data-integrity gate but breaks a causal identification assumption --
   with two new gates that catch it. Second, a direct empirical test of
   whether event-driven revision of the spatial weight matrix actually moves
   causal estimates, which tests LeSage and Pace's robustness claim.

   We don't claim the estimators are new. We claim the grain, the data
   regime, and those two findings are."


Q2: "WHAT'S YOUR MODEL CONFIDENCE AND ACCURACY?"
------------------------------------------------
  "It depends on which output, and we're explicit about that.

   For the observable outcome -- whether and when Amazon enables same-day in
   a ZCTA -- we backtest: train on facilities open through 2023, predict
   2024-25 openings, and report AUC, calibration error, and precision at 100.

   For the unobservable outcome -- dollar NPV -- we make no accuracy claim,
   because there's no public ground truth. Instead we report conformal
   prediction intervals with empirically verified coverage, and rank
   stability: how often a ZCTA stays in the top ten across ten thousand
   Monte Carlo draws.

   And we externally validate the one thing that can be checked -- metro-level
   capital expenditure against Amazon's 10-K, targeting within 25 percent."


Q3: "IT'S PUBLIC DATA. WHO ACTUALLY USES THIS?"
-----------------------------------------------
  "Three users with real decisions.

   Air-quality districts operating warehouse indirect-source rules -- South
   Coast AQMD's Rule 2305 is EPA-approved and others are copying it -- need to
   forecast where warehouses appear so they can plan mitigation capacity.

   City councils deciding on tax abatements need to know whether Amazon would
   have built there anyway. Our Heckman propensity score IS that
   counterfactual, and it's public money.

   And environmental-justice organisations need to know where the burden lands
   before the permit is filed, which is why we overlay predicted expansion on
   EPA EJScreen by demographic stratum -- a map that doesn't currently exist
   publicly.

   Proprietary data produces conclusions nobody can check. For a decision that
   communities have standing to contest, checkability is the product."
