# gravity-network/code

Archived. The question and the verdict are in
[`../../README.md`](../../README.md#gravity-network); not repeated here.

What is in this folder: thirteen modules in two families. `gravity_*.py` build
and report the gravity arms (`gravity_network.py` is the entry point);
`network_*.py` are the inference side — `network_inference.py` is the entry
point, with the sandwich estimator, the cluster bootstrap, the re-split
harness and the radius sensitivity beside it.

Imports point at `siting_atlas.*` paths that have since moved.
