# gravity-network/artefacts

The output of the programme described in
[`../../README.md`](../../README.md#gravity-network).

`gravity_network.json` holds the 13 network-proximity arms;
`network_inference.json` holds the sandwich and cluster-bootstrap inference on
them. Both are on the 483-decision expanded panel and both carry a `run_id`.

**Do not quote a single scalar from these.** The ranking of gravity against
nearest-distance depends on *k* — gravity loses at top-10 and wins at top-1 and
top-5 — and reporting only the top-10 figure is how it was first misread.
`docs/NUMBERS.md` §4 is the tie-breaker.
