# hazard-model/artefacts

The output of the programme described in
[`../../README.md`](../../README.md#hazard-model).

`hazard_report.json` is the original fit on 812 events;
`hazard_revival.json` is the rebuild on 5,441. Read them together — the point
of the pair is that more data did not help. Both were produced by the code in
[`../code/`](../code/) and are quoted by `docs/figures/fig08_backtest.png` and
`fig09_conformal_coverage.png`, which read them at build time.
