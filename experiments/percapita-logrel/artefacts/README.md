# percapita-logrel/artefacts

The output of the programme described in
[`../../README.md`](../../README.md#percapita-logrel).

`percapita_search.json` (eight count columns as rates over the numeraire) and
`logrel_search.json` (the log-relative arms, 41 repeats). Both were retired
out of `outputs/metrics/` on 2026-09-15.

**Not comparable to the current artefacts.** Both sit on the superseded
694-facility / 479-decision frame, so their baselines cannot be read against
`covariate_search.json`'s. Neither will be re-run. The per-replicate dumps
(11 MB of bootstrap draws) were deleted rather than archived; these summaries
carry the findings.
