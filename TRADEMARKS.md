# Trademarks and naming

**Siting Atlas is not affiliated with, endorsed by, or sponsored by
Amazon.com, Inc., Walmart Inc., Costco Wholesale Corporation, or any other
operator analysed in this project.**

## How operator names are used

Operator and service names appear in this project **descriptively**, to
identify the subject of study. That is nominative fair use and it is necessary:
you cannot write about a company's logistics network without naming the company.

## What we deliberately avoid

Third-party marks do **not** appear in:

- the project name
- the repository name
- the domain name
- the application title or any deployed URL
- the published dataset name

This is why the project is called Siting Atlas rather than anything containing
an operator's brand. A mark in descriptive prose is fine; the same mark in a
product name or a domain creates a likelihood of confusion.

## Before registering anything

Run a USPTO TESS search for the exact name in the relevant classes. Nothing in
this repository constitutes legal advice, and none of the contributors is a
lawyer. If this project is ever commercialised, take proper advice first.
