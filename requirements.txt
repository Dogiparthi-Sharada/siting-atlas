# Runtime dependencies for Siting Atlas.
#
# pyproject.toml is the SOURCE OF TRUTH. This file exists because many people
# and CI images expect a requirements.txt, and because `pip install -r` is the
# instruction most readers reach for first. It mirrors [project.dependencies]
# and is checked against it by scripts/preflight_publish.sh.
#
#     pip install -e .                 # preferred: installs the package too
#     pip install -r requirements.txt  # equivalent dependency set, no package
#
# Ranges, not pins. For the exact versions this project's results were produced
# with, use requirements-lock.txt instead -- that is the file to reach for if a
# number does not reproduce.
#
# Python >= 3.11 is required. The scripts under scripts/grid/ are a separate
# world: they run on a locked-down compute grid on Python 3.6 and install
# nothing from here.
